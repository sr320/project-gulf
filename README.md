# project-gulf

Methylation (MBD-BS) analysis of *C. virginica* gill tissue exposed to oil (SRA: SRP139854). See [plan.md](plan.md).

## Layout

- `code/` — numbered analysis scripts (Quarto/Rmd, shell), run in order
- `data/` — input data and metadata (`runinfo.csv`); large raw files are gitignored
- `output/` — results, one subdirectory per script in `code/`
